# 设计文档（监控软件）

界面稿：`app/design/preview.html`（能切页面、场景、深浅色、窗口尺寸），令牌：`app/design/tokens.css`。本地预览：`.claude/launch.json` 的 `design-preview`，或在 `app/design/` 下运行 `python -m http.server 8766`。两者冲突时以界面稿为准，本文记录"为什么"和不容易从稿子里看出来的规则。

视觉和基础交互**沿用现有的查看器**（一个更早的自用软件，参照位置见内部文档 `docs/internal.md`，公开仓库里没有这个文件）。下面"沿用"的部分，实现时直接对照它。

## 已定

### 沿用现有查看器

- **配色与字体**：中性灰、少框、少粗体（最多 500）、少颜色；陶土色只用于品牌和键盘焦点环。中文用 MiSans，等宽用 Cascadia Mono，数字等宽。数值见 `tokens.css`。
- **控件尺寸**：默认 32px、小号 28px；卡片圆角 12px、控件 8px；卡片头 44px、卡片尾 52px。
- **窗口**：默认 1160×720，最小 960×600；标题栏 44px，左段和侧栏同色、右段和内容区同色。
- **侧栏**：200px，上内边距 16px，第一项导航和页面标题文字中线对齐；品牌图标和导航图标左边缘在同一竖线上。主要页面在上，**设置、关于放在底部**，最底下是状态行（进行中的任务数、托管是否开启）。
- **页面标题行**（用户 2026-10-08 强调：专门设计过，照着做）：高 64px，标题 22/28/500，里面的控件 32px。文档页（连接、设置、关于）的标题行吸顶，用磨砂材质（系统关闭透明效果时退回实色）。**分隔线不占布局高度，只在下面的内容滚上来时才出现**。
- **滚动条**（同上，用户强调）：系统滚动条全部隐藏，每个滚动区一根**浮动滑块**，放在独立的固定层里，按滚动比例定位。轨道从吸顶标题下面 4px 开始。滚动或悬停时出现，停下 0.8 秒后淡出；可见宽度 4px，悬停或拖动时 6px 并变深；可以拖动。
- **像桌面软件**：默认不能选中文字（命令输出、汇报正文、等宽数据、输入框除外）；按钮用普通箭头指针。
- **弹出物、提示框、确认框、动效时长**：照现有查看器。后台刷新不产生动效；系统"减少动态效果"时全部关掉。

### 本软件自己的

- **页面**：任务、连接（用户 2026-10-08 定下这个叫法）、设置、关于；另有首次引导。
- **任务页**：列表和详情**并排**，选中任务不会盖掉列表。
  - 列表：进行中的任务固定在最上面，其余按天分组。进行中的行第二行显示最新一条进展，右边是实时用时。筛选：全部 / 进行中 / 失败或中断，以及项目。列表栏 320px（最小窗口时 288px），行的状态标记和页面标题左对齐。
  - 详情：顶部是名称、状态行（状态、项目、派活方和角色、开始时间、提交号）和操作（进行中的任务有"停止"）。下面四个标签：
    - **进展**：计划框在时间线顶部、整份替换，跟着内容滚走；滚过之后顶部吸一条 36px 单行计划条（计划 n/总数、进度条、当前项，点击回到顶部）。整块吸顶在小窗口下太占地方，2026-10-08 验收 003 时改定。命令可以展开看输出，失败的标红；思考默认隐藏。
    - **汇报**：上面一条摘要（提交、用时），下面是汇报正文。"TODO(design)"和"推断清单"两节用琥珀底高亮；没有这两节就不高亮。
    - **改动**、**参数**：细线分隔的行。
  - 失败、中断的任务，详情顶部用横幅直接说原因和下一步；中断的那条引导用户去打开托管。
- **不做"待验收"状态**（用户 2026-10-08）。任务只有进行中、已完成、失败、已中断四种。
- **连接页**：派活方（每个宿主一张卡片，列出各技能的版本和状态）和干活方（Codex 的版本、位置、能否运行）。用户自己改过或手装的技能标"不会自动替换"，替换必须先备份。
- **设置页**：派发默认值（下拉里显示"跟随 Codex（当前值）"）、托管、进度窗口、通知、外观、配置文件位置。环境变量覆盖某一项时，在那一行用琥珀色说明。改动立即写入，不要保存按钮；写入失败就恢复原值。模型下拉只有"跟随 Codex"和"自定义…"（Codex 的模型名会变，不写死列表）。通知、主题存软件自己的设置，不进 `config.json`。
- **关于页**：品牌标记、名称、版本、文件协议版本、一句介绍、"重新运行首次引导"。第三方组件声明不在界面上显示，放随包的 `THIRD_PARTY_NOTICES.md`（和现有查看器一样）。
- **连接页的 Codex 登录状态**：只显示已登录 / 未登录 / 无法确定，不显示账号。
- **更多菜单**：打开仓库文件夹、打开任务说明、打开汇报文件、打开进度文件、复制记录名、从列表隐藏（进行中禁用）。
- **停止**：确认框 `停止「<名称>」？` / `Codex 会立刻结束，工作区里没提交的改动会保留。`，危险按钮"停止"，默认焦点在取消。
- **通知**：系统通知，任务结束时发一条（已完成 / 失败 / 已中断：<名称>），点开选中该任务；启动时已结束的不发。
- **字体打包**（用户 2026-10-08 定）：随软件打包 MiSans VF。许可允许随软件分发、要求在软件里注明、不得改编、**不得单独分发字体文件**，所以：仓库里不放字体文件；构建脚本从官方下载页取，核对 SHA-256，打进安装包；不子集化、不转换；注明写在随包的第三方声明和 README 里（和现有查看器一样，界面上不显示）。在 004 实现。
- **品牌图标**（用户 2026-10-08 选 D2，设计负责人打磨定稿为 D2b）：图标库（Remix Icon）的许可**不允许把图标用作 logo 或应用图标**，全部自绘。图形是"回环"：一圈带实心箭头的弧线加中心一点，意思是派出去、干完、回来汇报。打磨要点：
  - 箭头从十二点方向挪到右上 45° 斜角，尖端顺时针指向右侧缺口。原稿顶部只留 1.5、底部 3.7，包围盒中心比圆心高 1.1，所以显得顶部挤、圆点偏下；现在四边都留 3.6。
  - 箭头收小到 4.0 × 2.8，中心点半径 2.9，整体按包围盒光学居中。
  - 源文件：`app/design/icons/mark.svg`（18px 以上，线宽 2.2）、`mark-small.svg`（16、20px，线宽 2.6）、`app.svg`（应用图标：克莱因蓝底板 + 白色标记）。打磨过程见 `icons-d.html`，打开可以看测量辅助线。
- **品牌色**（用户 2026-10-08 定）：克莱因蓝。浅色主题 `#002FA7`（白底 10.7:1）；深色主题用同色相提亮的 `#6684FF`（深底 5.5:1，原色只有 1.7:1）。令牌 `--brand`；键盘焦点环 `--focus` 也改用品牌色（原来是陶土色）。应用图标是克莱因蓝实色底板 + 白色图形，不随主题变。陶土色不再使用（它是 Claude 的品牌色，开源第三方工具用它容易被看成官方出品）。
