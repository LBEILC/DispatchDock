# 各宿主的差异

技能正文只写一份：`skills/<技能>/SKILL.md`。它本身就是 **Claude Code 版**，直接复制到 `~/.claude/skills/<技能>/` 就能用。其他宿主只在这里放和 Claude Code 不同的部分，由安装命令合成。

## 正文里的可替换段

正文中和宿主有关的段落用一对 HTML 注释标出来，名字只用小写字母、数字和连字符：

```markdown
<!-- host:dispatch -->
3. **后台派发**：用 Bash 工具，设 `run_in_background: true`……
<!-- /host:dispatch -->
```

- 标记各占一行（行首可以有空格，用来留在列表项里），不嵌套，同一个名字在一份正文里只出现一次。替换时连同标记行整行替换，替换内容的缩进由差异文件自己写好。
- 标记对 Markdown 渲染和 agent 阅读都没有影响。安装时保留或去掉都可以；合成结果里统一去掉。
- 和宿主无关的内容不要放进标记里。只有确实需要换掉的段落才标。

## 差异文件

`skills/_hosts/<宿主>/<技能>.md`，宿主名和派发清单里的 `dispatcher.host` 相同（`devin`）。内容分两部分，都可以省略：

1. **frontmatter**（开头的 `---` 块）：按**顶层键**覆盖正文的 frontmatter。差异文件里出现的键整个替换正文里的同名键，没出现的保留正文的。
2. **替换段**：和正文相同的标记对。同名段整个替换正文里的那一段；内容为空就是删掉这一段。

合成规则：

- 差异文件里出现正文没有的段名，安装命令报错，不猜测。
- 正文里有、差异文件里没有的段，保留正文原样。
- 合成后检查：结果里不能再出现 `<!-- host:` 标记，frontmatter 的 `name` 和正文相同。

## 写正文时注意

- 不写宿主名称、工具名、版本号这些只对一个宿主成立的东西；写不开的就放进可替换段。
- 技能目录用"本文件所在目录"指代，不写死路径。
- 新增一个宿主：在这里加一个目录，写出所有需要替换的段；安装命令加上它的技能目录位置。
